# MestreOS: pacotes abertos

Material aberto do **MestreOS**, o sistema operacional pessoal que transforma o seu agente de IA (Claude Code, Codex ou Cursor) num parceiro que conhece você, seus projetos e suas regras. O Mestre do MestreOS é o Paulo Penna: arquiteto de BH, fundador da Eureka Labs, piloto de helicóptero, opera o próprio OS todo dia.

O núcleo do MestreOS (instalador, skills e robôs) não fica aqui. Cada aluno pega o seu código pessoal no [portal do aluno](https://mestreos-preview.vercel.app/portal/licenca) e o próprio agente instala e atualiza ("atualiza o meu MestreOS").
